# TimeSprout

TimeSprout 是一个轻量级的日程管理工具。它可以根据作息、课程、固定事项和任务，自动生成当天的可执行时间轴。

在线体验：[dffapi.top](https://dffapi.top)

## 功能

- 今日时间轴：自动安排任务，并支持开始、完成、延后和跳过
- 日历视图：按月查看课程、任务和临时事项，并在指定日期添加任务
- 四象限：按“重要 / 紧急”整理待办事项
- 番茄专注：25 分钟专注与 5 分钟休息，记录累计专注时间
- 每周课表：管理固定课程并提示时间冲突
- 假期规划：按日期生成学习任务，同时保留每日玩乐时间
- 中英文界面：支持中文和 English 切换
- 备份与恢复：导出或导入 `.txt` 计划备份
- 逾期处理：集中查看逾期任务并重新安排
- 页面内提醒：任务开始前 10 分钟、开始时和逾期后提醒

## 快速开始

项目没有构建步骤或第三方依赖，直接用浏览器打开 [`index.html`](./index.html) 即可使用。

也可以启动一个本地静态服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 测试

测试需要支持 `node:test` 的 Node.js 版本：

```bash
node --check planner.test.js
node --test planner.test.js
```

测试脚本会读取 `index.html` 中的应用脚本，覆盖排程、跨天作息、冲突检测、国际化、备份、提醒和主要交互行为。

## 数据说明

- 计划保存在当前浏览器的 `localStorage` 中，存储键为 `student-agenda-single-v1`
- 当前版本不需要登录或后端服务，数据不会自动同步到其他设备
- 清除浏览器站点数据会删除本地计划；重要数据请先在“设置”中导出备份
- 导入备份前会先校验文件格式，并要求连续两次确认后才替换当前计划
- 提醒只显示在打开的网页内，不会发送系统通知或向外传输计划数据

## 使用建议

1. 在“设置”中先填写起床、睡觉和每日玩乐时间。
2. 在“课表”中添加每周固定课程。
3. 回到“今日”添加任务或临时事项，系统会避开固定安排自动排程。
4. 使用“四象限”和“专注”视图管理当前最重要的一件事。
5. 定期导出备份，便于更换浏览器或设备时恢复计划。

## 当前限制

- 暂无账号、云同步、多设备同步和移动端原生通知
- 数据依赖浏览器本地存储
- 应用目前采用单 HTML 文件结构，适合直接分发和离线使用
