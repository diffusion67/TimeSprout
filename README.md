# TimeSprout

[English README](./README.en.md)

TimeSprout 是一个轻量级的日程管理工具。它可以根据作息、课程、固定事项和任务，自动生成当天的可执行时间轴。

在线体验：[dffapi.top](https://dffapi.top)

## 功能

- 今日时间轴：自动安排任务，并支持开始、完成、延后和跳过
- 日历视图：按月查看课程、任务和临时事项，并在指定日期添加任务
- 四象限：按“重要 / 紧急”整理待办事项
- 番茄专注：25 分钟专注与 5 分钟休息，按实际专注秒数累计（包括未完成的番茄）
- 数据分析：查看近 7 天或近 30 天的完成率、专注时长、逾期任务、连续完成天数和每日时间分配
- 外观选择：支持跟随系统、浅色和深色主题
- 每周课表：管理固定课程并提示时间冲突
- 假期规划：按日期生成学习任务（单次最多 366 天），同时保留每日玩乐时间
- 中英文界面：支持中文和 English 切换
- 备份与恢复：导出 `TimeSprout backup v2` `.txt` 备份，并可导入有效的 v1 或 v2 备份（文件上限 5 MiB）
- 逾期处理：集中查看逾期任务；“延后”会移到下一规划日的睡觉截止时间
- 页面内提醒：任务开始前 10 分钟、开始时和逾期后提醒
- 活力成长界面：统一成长色彩、卡片、表单和反馈状态，浅色与深色主题均可使用
- 响应式导航：桌面端可在顶部导航与侧边栏之间切换；手机端固定“今日、日历、专注、更多”底部导航
- 减少动态效果：遵从系统的“减少动态效果”偏好，降低页面过渡与动画干扰

## 快速开始

浏览器版没有构建步骤或第三方依赖，直接用浏览器打开 [`index.html`](./index.html) 即可使用。

也可以启动一个本地静态服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## Windows 与 Android 安装版

两个安装版沿用相同的页面，因此今日、日历、四象限、专注、数据、课表、假期、设置、中英界面及备份功能保留原有布局与行为。各设备的数据仍单独保存在本地，可用备份文件转移。

- Windows：在 Windows 上运行 `npm ci` 和 `npm run build:windows`，安装程序输出到 `dist/`。开发时可运行 `npm run desktop`。关闭窗口后程序留在系统托盘，继续发送带系统提示音的通知；从托盘菜单退出。实际声音受 Windows 通知设置控制。
- Android：安装 JDK 17、Android SDK Platform 35 与 Build Tools 35，进入 `android` 后在 Windows 上运行 `.\gradlew.bat assembleDebug`，或在 macOS/Linux 上运行 `./gradlew assembleDebug`。调试版使用 Gradle 在本机生成的默认调试签名；可直接安装的 APK 位于 `android/app/build/outputs/apk/debug/app-debug.apk`。Android 13 及以上需允许通知；Android 12 及以上建议允许精确提醒，否则系统可能延迟通知。提醒使用 TimeSprout 通知渠道的默认提示音，重启设备后会恢复已安排的提醒。

安装版预排未来完整 168 小时内的提醒，并在计划变动或打开应用时更新。Android 版至少每周打开一次，以延续提醒范围。

## 测试

测试需要支持 `node:test` 的 Node.js 版本：

```bash
npm test
```

测试脚本会读取 `index.html` 中的应用脚本。目前包含 195 项 Node.js 测试，覆盖排程、跨天作息、冲突检测、国际化、备份、原生提醒、专注计时和主要交互行为，并验证导航布局、持久化、备份往返、旧数据迁移及中英文导航。`android/tests/` 另有独立的 JVM 提醒回归测试，不包含在 `npm test` 中。

## 数据说明

- 计划保存在当前运行环境的 `localStorage` 中，存储键为 `student-agenda-single-v1`
- 当前版本不需要登录或后端服务，数据不会自动同步到其他设备
- 清除浏览器站点数据或安装版应用数据会删除本地计划；重要数据请先在“设置”中导出备份
- 导入备份前会先校验文件格式，并要求连续两次确认后才替换当前计划
- 桌面端导航布局会随计划一同保存在本地备份中；旧版计划会自动采用顶部导航，避免升级后改变原有使用习惯
- 浏览器版在网页打开时显示页面内提醒；安装版另外安排本机系统通知，不向外传输计划数据

### 数据分析与外观

在“数据”中查看近 7 天或近 30 天的完成率、专注时长、当前逾期任务、连续完成天数和每日时间分配。统计保存在当前浏览器，并包含在 `TimeSprout backup v2` 备份中。

时间分配中的课程、事项和玩乐按当前记录中的计划估算。查看过去日期时，任务时间包含该日已记录的完成时长，以及明确指定到该日但仍待完成的任务计划时长；未指定日期的待办不会回填到过去。完成时长取任务原定分钟数，并非计时器测得的实际耗时。

任务时长使用整分钟。旧本地数据中的小数分钟会向上取整以保留任务；导入备份时会拒绝含小数分钟任务的文件。

在“设置”的“外观”中选择跟随系统、浅色或深色。主题选择会随本地计划和备份保存。

## 使用建议

1. 在“设置”中先填写起床、睡觉和每日玩乐时间。
2. 在“课表”中添加每周固定课程。
3. 回到“今日”添加任务或临时事项，系统会避开固定安排自动排程。
4. 使用“四象限”和“专注”视图管理当前最重要的一件事。
5. 在“设置”中按习惯选择顶部导航或侧边栏导航；手机端始终使用统一底部导航，并可通过“更多”进入全部功能。
6. 定期导出备份，便于更换浏览器或设备时恢复计划。

## 项目结构

```text
index.html                           # 单文件应用：HTML、CSS 和 JavaScript
package.json / package-lock.json     # 桌面版依赖、构建命令及 Node.js 测试命令
planner.test.js                      # Node.js 测试与交互测试工具
audit-*.test.js                      # 缺陷回归测试
native-reminders-regressions.test.js # 原生提醒回归测试
windows/                             # Windows 通知、托盘、安装包入口和提醒存储测试
android/                             # Android 通知、APK 工程和独立 JVM 测试
LICENSE                              # MIT License
```

`node_modules/`、`dist/` 和 Android 构建输出由依赖安装或构建命令生成，不纳入版本控制。

## 当前限制

- 暂无账号、云同步和多设备自动同步；Android 安装版可发送设备原生通知
- 数据依赖当前运行环境的本地存储
- 应用目前采用单 HTML 文件结构，适合直接分发和离线使用
